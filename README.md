# 🕷️ Metodologia Scrape

Este repositório contém a metodologia e scripts desenvolvidos para extração de dados eficiente e estruturada.

## 📄 Conteúdo

*   **`Metodologia-Scrape.md`**: Documento detalhado explicando os princípios, técnicas e ética de scraping adotados.
*   **`scrape.js`**: Script base em Node.js (Puppeteer/Playwright) para execução das tarefas de extração.

## 🚀 Objetivo

Fornecer um framework reutilizável para coleta de dados na web, focado em:
1.  **Resiliência:** Lidar com falhas de rede e bloqueios.
2.  **Estrutura:** Dados limpos e prontos para análise.
3.  **Performance:** Execução otimizada para ambientes com recursos limitados.
